# Exercise 4.1: SVG House

## Project Overview
For this exercise, I added an original SVG graphic of a house and its surroundings to my webpage. To practice working with vector graphics and code, I then duplicated the graphic and modified the SVG code to create a sunset scene with additional details. 

The page features a side-by-side "Before and After" comparison, along with a table documenting the exact code changes.

## Modifications Made
I made four specific edits to the SVG code to fulfill the exercise requirements:

1. **Changing/Moving Shapes:** Moved the door knob from the right side of the door to the left side (changed the `cx` coordinate from `430` to `390`).
2. **Changing Fill Colors:** Changed the sky `<rect>` fill color from daytime light blue to an evening coral (`#FF7F50`).
3. **Changing Attributes of Strokes:** Made the sun rays thicker and more prominent by increasing the `stroke-width` attribute from `6` to `12`.
4. **Adding Other Items:** Added a grey stone path using a `<polygon>` tag to draw a 3D perspective walkway leading from the front door down to the bottom edge of the picture.
